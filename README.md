# Sistema Integral de Gestión de Restaurante (SIGR) — Línea Base v1.0.0

Aplicación web monolítica modular desarrollada en Python con Flask y SQLite para administrar las operaciones fundamentales de un restaurante: control de usuarios por roles, menú digital, toma de pedidos, reservas, ventas y cierre de caja diario.
